# Demo inventory: real items, real listings

Four framed prints from the author's "Lone Journey" series, photographed by the author and
listed for real on Facebook Marketplace at $35 each (5x5, 1 of 1).

`listings.json` is genuine crew output (curator, appraiser, copywriter on Google ADK + Gemini),
produced by `python -m scripts.build_inventory` with the seller's notes. Photos are uploaded
back-of-frame FIRST on purpose: the curator still picks the front as the storefront photo.
The appraiser's suggested price is kept next to the seller's real price, so the difference
between "what the AI suggests" and "what the human decides" stays visible.

of this repository's code.
